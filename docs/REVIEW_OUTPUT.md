# Calibration Review Output

Historical scans can be exported for review.

Each row records:
- zone id
- detection timestamp
- BUY or SELL
- entry timeframe
- exact zone boundaries
- provisional rejection score
- PLAN_READY or SKIP
- every skip reason
- required confirmation timeframe when ready
- execution number
- minimum R:R
- risk setting
- candle-close invalidation rule

This output is for calibration. It must not be presented as verified trading advice or as proof that the strategy works.
